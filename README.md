# SmartTaskManager

## Overview
Smart Task Manager is a desktop application built using WPF (Windows Presentation Foundation) and the MVVM architecture pattern. It allows users to efficiently manage daily tasks with a clean and responsive UI.

## Features
Add new tasks with title, priority, and due date
Mark tasks as completed
Delete tasks
Real-time search and filtering
Priority-based color indicators
Live dashboard showing:
  Total tasks
  Completed tasks
  Pending tasks
  Completion percentage

## Technologies Used
C# , WPF (.NET), MVVM Architecture, Data Binding, ICommand (RelayCommand), ObservableCollection

## How to Run
1. Clone the repository
2. Open solution in Visual Studio
3. Build and run the project
